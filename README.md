# Flash Property Consultants

A multi-page React + Vite website for Flash Property Consultants, Islamabad.

## Run locally

```bash
npm install
npm run dev
```

## Upload to GitHub

1. Create a new empty GitHub repository.
2. Upload all files inside this folder, including `package.json`, `src`, `public`, and `vercel.json`.
3. Commit the files.

## Deploy on Vercel

1. Open Vercel and choose **Add New Project**.
2. Import the GitHub repository.
3. Keep the framework preset as **Vite**.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Click **Deploy**.

The included `vercel.json` keeps all website routes working when visitors refresh a page such as `/properties` or `/contact`.
